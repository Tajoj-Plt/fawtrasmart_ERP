# دليل نظام حساب النقاط (Points Calculation System)

## 📚 نظرة عامة

نظام حساب النقاط في **Ecosystem Module** يوفر طريقة مرنة وديناميكية لحساب النقاط للعملاء والموظفين بناءً على إجراءاتهم المختلفة.

---

## 🎯 أنواع حساب النقاط (Calculation Types)

### 1️⃣ النقاط الثابتة (`fixed`)

#### الوصف
نقاط ثابتة لا تتغير بتغير المبلغ أو القيمة. نفس عدد النقاط دائماً بغض النظر عن أي عوامل.

#### متى تستخدمه؟
- عندما تريد مكافأة ثابتة لا تعتمد على القيمة
- للإجراءات البسيطة (حضور، غياب، إتمام مهمة)
- للمكافآت والعقوبات الثابتة

#### الحقول المطلوبة
- ✅ `points` - عدد النقاط الثابت
- ❌ `calculation_value` - غير مطلوب
- ❌ `tiers_config` - غير مطلوب

#### أمثلة عملية

**مثال 1: زيارة العميل**
```php
[
    'action_type' => 'visit_completed',
    'action_name' => 'زيارة مكتملة',
    'points' => 3,
    'calculation_type' => 'fixed',
    'calculation_value' => null,
]
```
**النتيجة:**
- أي زيارة = **3 نقاط** ✅
- سواء زيارة قصيرة أو طويلة
- لا يهم نوع العميل

**مثال 2: غياب الموظف**
```php
[
    'action_type' => 'absence',
    'action_name' => 'غياب',
    'points' => -20,
    'calculation_type' => 'fixed',
]
```
**النتيجة:**
- أي غياب = **خصم 20 نقطة** ❌

**مثال 3: إحالة عميل جديد**
```php
[
    'action_type' => 'referral',
    'points' => 50,
    'calculation_type' => 'fixed',
]
```
**النتيجة:**
- كل إحالة ناجحة = **50 نقطة** 🎁

---

### 2️⃣ نقطة لكل مبلغ (`per_amount`)

#### الوصف
نقطة واحدة لكل مبلغ محدد من المال. كلما زاد المبلغ، زادت النقاط بشكل خطي ومتناسب.

#### متى تستخدمه؟
- عندما تريد ربط النقاط بالمبلغ بشكل مباشر
- لتشجيع الفواتير والمعاملات الأكبر
- للعمل الإضافي (ساعات، أيام)

#### الحقول المطلوبة
- ✅ `calculation_value` - المبلغ لكل نقطة (مثال: 50 = نقطة لكل 50 ريال)
- ✅ `points` - القيمة الافتراضية
- ⚠️ `min_amount` - اختياري (الحد الأدنى)
- ⚠️ `max_amount` - اختياري (الحد الأقصى)
- ⚠️ `max_points` - اختياري (سقف النقاط)
- ❌ `tiers_config` - غير مطلوب

#### معادلة الحساب
```
النقاط = المبلغ ÷ calculation_value
(مع تطبيق min_amount و max_amount و max_points إن وجدت)
```

#### أمثلة عملية

**مثال 1: فاتورة الموظف**
```php
[
    'action_type' => 'invoice_created',
    'action_name' => 'إنشاء فاتورة',
    'points' => 5,
    'calculation_type' => 'per_amount',
    'calculation_value' => 200,      // نقطة لكل 200 ريال
    'min_amount' => 100,             // أقل من 100 = لا شيء
    'max_points' => 25,              // سقف أقصى
]
```

**جدول النتائج:**

| قيمة الفاتورة | الحساب | النقاط الفعلية | الملاحظات |
|---------------|---------|----------------|-----------|
| 50 ريال | - | **0 نقطة** | أقل من min_amount |
| 100 ريال | 100 ÷ 200 = 0.5 | **0 نقطة** | لم نصل لنقطة كاملة |
| 400 ريال | 400 ÷ 200 = 2 | **2 نقطة** ✅ | |
| 1000 ريال | 1000 ÷ 200 = 5 | **5 نقاط** ✅ | |
| 10000 ريال | 10000 ÷ 200 = 50 | **25 نقطة** | سقف max_points |

**مثال 2: سند قبض للعميل**
```php
[
    'action_type' => 'receipt_created',
    'calculation_type' => 'per_amount',
    'calculation_value' => 50,       // نقطة لكل 50 ريال
    'max_points' => 50,
]
```

**جدول النتائج:**

| المبلغ | الحساب | النقاط |
|--------|--------|--------|
| 100 ريال | 100 ÷ 50 = 2 | **2 نقطة** |
| 500 ريال | 500 ÷ 50 = 10 | **10 نقاط** |
| 3000 ريال | 3000 ÷ 50 = 60 | **50 نقطة** (السقف) |

**مثال 3: عمل إضافي (بالساعات)**
```php
[
    'action_type' => 'overtime_hours',
    'calculation_type' => 'per_amount',
    'calculation_value' => 1,        // نقطة لكل ساعة
    'points' => 3,                   // 3 نقاط للساعة
    'max_amount' => 8,               // حد أقصى 8 ساعات
    'max_points' => 24,
]
```

**جدول النتائج:**

| الساعات | النقاط |
|---------|--------|
| ساعة واحدة | **3 نقاط** |
| 4 ساعات | **12 نقطة** |
| 8 ساعات | **24 نقطة** (السقف) |
| 10 ساعات | **24 نقطة** (يتوقف عند max_amount) |

### 3️⃣ النسبة المئوية (`percentage`)

#### الوصف
نسبة مئوية من قيمة المعاملة. النقاط تُحسب كنسبة من المبلغ الإجمالي.

#### متى تستخدمه؟
- عندما تريد مكافأة عادلة متناسبة مع المبلغ
- للعمولات والحوافز
- لحساب الخصومات والمرتجعات

#### الحقول المطلوبة
- ✅ `calculation_value` - النسبة المئوية (مثال: 1.0 = 1%)
- ✅ `points` - القيمة الافتراضية
- ⚠️ `min_amount` - اختياري (الحد الأدنى)
- ⚠️ `max_points` - اختياري (سقف النقاط)
- ❌ `tiers_config` - غير مطلوب

#### معادلة الحساب
```
النقاط = المبلغ × (calculation_value ÷ 100)
(مع تطبيق min_amount و max_points إن وجدت)
```

#### أمثلة عملية

**مثال 1: دفع فاتورة للعميل**
```php
[
    'action_type' => 'invoice_paid',
    'action_name' => 'دفع فاتورة',
    'points' => 10,
    'calculation_type' => 'percentage',
    'calculation_value' => 1.0,      // 1% من المبلغ
    'min_amount' => 100,             // لا نقاط لأقل من 100
    'max_points' => 200,             // سقف أقصى
]
```

**جدول النتائج:**

| المبلغ المدفوع | الحساب | النقاط | الملاحظات |
|----------------|---------|--------|-----------|
| 50 ريال | - | **0** | أقل من min_amount |
| 200 ريال | 200 × 1% = 2 | **2 نقطة** ✅ | |
| 1000 ريال | 1000 × 1% = 10 | **10 نقاط** ✅ | |
| 5000 ريال | 5000 × 1% = 50 | **50 نقطة** ✅ | |
| 30000 ريال | 30000 × 1% = 300 | **200 نقطة** | سقف max_points |

**مثال 2: مرتجع (خصم)**
```php
[
    'action_type' => 'return_invoice',
    'action_name' => 'مرتجع',
    'points' => -10,
    'calculation_type' => 'percentage',
    'calculation_value' => 0.5,      // 0.5% خصم
]
```

**جدول النتائج:**

| قيمة المرتجع | الحساب | النقاط |
|--------------|---------|--------|
| 1000 ريال | 1000 × 0.5% = 5 | **خصم 5 نقاط** ❌ |
| 4000 ريال | 4000 × 0.5% = 20 | **خصم 20 نقطة** ❌ |

**مثال 3: تحصيل دفعة للموظف**
```php
[
    'action_type' => 'payment_collected',
    'calculation_type' => 'percentage',
    'calculation_value' => 0.5,      // 0.5%
    'min_amount' => 200,
    'max_points' => 15,
]
```

**جدول النتائج:**

| المبلغ المحصل | الحساب | النقاط |
|---------------|---------|--------|
| 100 ريال | - | **0** (أقل من min) |
| 1000 ريال | 1000 × 0.5% = 5 | **5 نقاط** |
| 5000 ريال | 5000 × 0.5% = 25 | **15 نقطة** (السقف) |

### 4️⃣ المستويات المتدرجة (`tiered`)

#### الوصف
نقاط مختلفة حسب نطاقات المبلغ. كل نطاق (tier) له عدد نقاط خاص، مما يشجع على الوصول للمستويات الأعلى.

#### متى تستخدمه؟
- عندما تريد تشجيع الفواتير الكبيرة بشكل أكبر
- لإنشاء حوافز متدرجة تصاعدية
- لقياس الأداء بمستويات

#### الحقول المطلوبة
- ✅ `tiers_config` - مصفوفة JSON بالمستويات
- ✅ `points` - القيمة الافتراضية
- ⚠️ `min_amount` - اختياري (الحد الأدنى)
- ⚠️ `max_points` - اختياري (سقف النقاط)
- ❌ `calculation_value` - غير مطلوب

#### بنية tiers_config
```json
[
    {"min": 50, "max": 100, "points": 5},
    {"min": 100, "max": 300, "points": 10},
    {"min": 300, "max": 500, "points": 20},
    {"min": 500, "max": null, "points": 35}
]
```
⚠️ **ملاحظة:** `"max": null` في المستوى الأخير يعني "فما فوق"

#### أمثلة عملية

**مثال 1: فاتورة العميل (متدرجة)**
```php
[
    'action_type' => 'invoice_created',
    'action_name' => 'إنشاء فاتورة',
    'points' => 5,
    'calculation_type' => 'tiered',
    'min_amount' => 50,
    'max_points' => 100,
    'tiers_config' => json_encode([
        ['min' => 50,   'max' => 100,  'points' => 5],
        ['min' => 100,  'max' => 300,  'points' => 10],
        ['min' => 300,  'max' => 500,  'points' => 20],
        ['min' => 500,  'max' => 1000, 'points' => 35],
        ['min' => 1000, 'max' => 2000, 'points' => 50],
        ['min' => 2000, 'max' => null, 'points' => 75],
    ])
]
```

**جدول النتائج:**

| قيمة الفاتورة | النطاق | النقاط | الملاحظات |
|---------------|---------|--------|-----------|
| 30 ريال | - | **0** | أقل من min_amount |
| 75 ريال | 50-100 | **5 نقاط** ✅ | المستوى الأول |
| 150 ريال | 100-300 | **10 نقاط** ✅ | المستوى الثاني |
| 400 ريال | 300-500 | **20 نقطة** ✅ | المستوى الثالث |
| 750 ريال | 500-1000 | **35 نقطة** ✅ | المستوى الرابع |
| 1500 ريال | 1000-2000 | **50 نقطة** ✅ | المستوى الخامس |
| 5000 ريال | 2000+ | **75 نقطة** ✅ | المستوى الأعلى |
| 50000 ريال | 2000+ | **75 نقطة** | لا يتجاوز المستوى الأخير |

**الرسم البياني:**
```
75 نقطة  ███████████████ (2000+)
50 نقطة  ██████████ (1000-2000)
35 نقطة  ███████ (500-1000)
20 نقطة  ████ (300-500)
10 نقاط  ██ (100-300)
5 نقاط   █ (50-100)
```

**مثال 2: تحقيق هدف المبيعات للموظف**
```php
[
    'action_type' => 'sales_target_achieved',
    'action_name' => 'تحقيق هدف المبيعات',
    'points' => 50,
    'calculation_type' => 'tiered',
    'max_points' => 200,
    'tiers_config' => json_encode([
        ['min' => 80,  'max' => 100, 'points' => 50],   // 80-100%
        ['min' => 100, 'max' => 120, 'points' => 100],  // 100-120%
        ['min' => 120, 'max' => 150, 'points' => 150],  // 120-150%
        ['min' => 150, 'max' => null, 'points' => 200], // 150%+
    ])
]
```

**جدول النتائج:**

| نسبة تحقيق الهدف | النطاق | النقاط | الوصف |
|------------------|---------|--------|-------|
| 85% | 80-100% | **50 نقطة** ✅ | أداء مقبول |
| 100% | 100-120% | **100 نقطة** 🎯 | تحقيق الهدف |
| 130% | 120-150% | **150 نقطة** 🌟 | أداء ممتاز |
| 200% | 150%+ | **200 نقطة** 🏆 | أداء استثنائي |

**مثال 3: رضا العميل (تقييم 1-5)**
```php
[
    'action_type' => 'customer_satisfaction',
    'action_name' => 'رضا العميل',
    'calculation_type' => 'tiered',
    'max_points' => 15,
    'tiers_config' => json_encode([
        ['min' => 1, 'max' => 3, 'points' => 2],

        ['min' => 4, 'max' => 5, 'points' => 10],
```

**جدول النتائج:**

| التقييم | النقاط | الرمز |

## 📊 جدول المقارنة السريعة

| الخاصية | fixed | per_amount | percentage | tiered |
|---------|-------|------------|-----------|--------|
| **يتأثر بالمبلغ؟** | ❌ لا | ✅ نعم (خطي) | ✅ نعم (نسبي) | ✅ نعم (مستويات) |
| **calculation_value** | ❌ غير مطلوب | ✅ مطلوب | ✅ مطلوب | ❌ غير مطلوب |
| **tiers_config** | ❌ غير مطلوب | ❌ غير مطلوب | ❌ غير مطلوب | ✅ مطلوب (JSON) |
| **min_amount** | ⚠️ اختياري | ⚠️ اختياري | ⚠️ اختياري | ⚠️ اختياري |
| **max_amount** | ⚠️ اختياري | ⚠️ اختياري | ⚠️ اختياري | ⚠️ اختياري |
| **max_points** | ⚠️ اختياري | ⚠️ اختياري | ⚠️ اختياري | ⚠️ اختياري |
| **مناسب لـ** | إجراءات بسيطة | فواتير، مبيعات | عمولات، نسب | حوافز متدرجة |
| **مثال** | 3 نقاط دائماً | نقطة/200 ريال | 1% من المبلغ | 5-10-20-35 نقطة |

## 🔄 الفروقات بين العملاء والموظفين

### العملاء (Clients)
- 🎁 نقاط أكثر سخاءً لتشجيع المشتريات
- 💰 تركيز على الفواتير والمدفوعات
- 🎯 استخدام أكثر للـ `tiered` للفواتير الكبيرة
- 🎊 مكافآت خاصة (عيد ميلاد، أول شراء)

### الموظفين (Employees)
- 📊 نقاط محدودة مرتبطة بالأداء
- ⏰ تركيز على الحضور والإنتاجية
- 🎯 استخدام `tiered` لقياس الأداء والأهداف
- ⚡ عقوبات على التأخير والغياب

### مثال مقارن: إنشاء فاتورة

#### للعميل:
```php
'calculation_type' => 'tiered',
'tiers_config' => [ /* 6 مستويات: 5-75 نقطة */ ]
```
- فاتورة 1000 ريال = **50 نقطة**

#### للموظف:
```php
'calculation_type' => 'per_amount',
'calculation_value' => 200,
'max_points' => 25,
```
- فاتورة 1000 ريال = **5 نقاط** (1000÷200)

## 🎨 أمثلة استخدام في الكود

### استخدام calculatePoints() في Model

```php
use App\Models\Ecosystem\PointsSetting;

// الحصول على إعداد النقاط
$setting = PointsSetting::where('user_type', 'client')
    ->where('action_type', 'invoice_created')
    ->where('is_active', true)
    ->first();

// حساب النقاط
$amount = 1500; // قيمة الفاتورة
$points = $setting->calculatePoints($amount);

echo "فاتورة بقيمة {$amount} ريال = {$points} نقطة";
```

## 📝 نصائح وأفضل الممارسات

### ✅ افعل (Do's)

1. **استخدم `fixed` للإجراءات البسيطة**
   - حضور، غياب، إتمام مهمة
   
2. **استخدم `percentage` للعمولات**
   - 1% من المبيعات الشهرية
   - 0.5% من المرتجعات (خصم)

3. **استخدم `tiered` للحوافز**
   - تشجيع الفواتير الكبيرة
   - قياس الأداء بمستويات

4. **حدد `max_points` دائماً**
   - لمنع النقاط غير المحدودة
   - للتحكم في التكاليف

5. **استخدم `min_amount` للجودة**
   - تجاهل المعاملات الصغيرة جداً

### ❌ لا تفعل (Don'ts)

1. **لا تستخدم `percentage` عالية جداً**
   - ❌ 10% = 100 نقطة لكل 1000 ريال (مكلف جداً)
   - ✅ 1% = 10 نقاط لكل 1000 ريال (معقول)

2. **لا تنسى `max_points`**
   - بدونها: فاتورة مليون ريال = نقاط فلكية!

3. **لا تعقد `tiers_config` أكثر من اللازم**
   - ❌ 20 مستوى = معقد ومربك
   - ✅ 4-6 مستويات = واضح وفعال

4. **لا تستخدم `tiered` للإجراءات البسيطة**
   - حضور الموظف = `fixed` فقط
