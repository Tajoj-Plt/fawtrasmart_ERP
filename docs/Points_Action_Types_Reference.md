## 🔢 أنواع الحساب (Calculation Types)

| النوع | القيمة | الوصف | مثال |
|-------|--------|-------|------|
| **ثابت** | `fixed` | نقاط ثابتة لكل عملية بغض النظر عن المبلغ | `points = 5` → دائماً 5 نقاط |
| **نسبة مئوية** | `percentage` | نسبة من قيمة المعاملة المالية | `calculation_value = 1.0` → 1% من المبلغ |
| **لكل مبلغ** | `per_amount` | نقطة واحدة لكل X ريال | `calculation_value = 50` → نقطة لكل 50 ريال |
| **متدرج** | `tiered` | مستويات متدرجة حسب قيمة المعاملة | حسب `tiers_config` |

## 🔗 الإجراءات المشتركة (موظف + عميل)

هذه الإجراءات لها إعدادان — واحد للعميل وآخر للموظف. عند استدعاء `processAction()` تتم معالجة الاثنين تلقائياً:

| `action_type` | العميل | الموظف |
|--------------|--------|--------|
| `invoice_created` | tiered: 5-75 نقطة | per_amount: 1 لكل 200 ر.س |
| `receipt_created` | per_amount: 1 لكل 50 ر.س | per_amount: 1 لكل 500 ر.س |
| `payment_voucher` | fixed: **-5** (خصم) | fixed: +2 (منح) |
| `visit_completed` | fixed: 3 | fixed: 5 |

## 💡 كيفية الاستخدام في الكود

### منح تلقائي (processAction)
```php
// يبحث عن جميع الإعدادات المطابقة (موظف + عميل) ويعالجها تلقائياً
$results = app(PointsService::class)->processAction('receipt_created', [
    'employee_id'    => $user->employee_id,
    'client_id'      => $clientId,
    'amount'         => $receipt->amount,
    'branch_id'      => $receipt->branch_id,
    'reference_type' => Receipt::class,
    'reference_id'   => $receipt->id,
]);

// النتائج
$results['employee']; // PointsResult|null
$results['client'];   // PointsResult|null
$results['settings_found']; // int
```

### عكس بالمرجع (reverseByReference)
```php
// يعكس جميع معاملات النقاط المرتبطة بمرجع معين
$result = app(PointsService::class)->reverseByReference(
    Receipt::class,
    $receipt->id,
    'إلغاء سند قبض رقم ' . $receipt->code
);

// النتائج
$result['reversed']; // عدد المعاملات المعكوسة بنجاح
$result['failed'];   // عدد المعاملات التي فشل عكسها
$result['total'];    // إجمالي المعاملات الموجودة
```

### منح يدوي
```php
// منح نقاط لموظف
app(PointsService::class)->awardEmployee($employeeId, 'performance_bonus');

// منح نقاط لعميل
app(PointsService::class)->awardClient($clientId, 'first_purchase');

// خصم نقاط
app(PointsService::class)->deductEmployee($employeeId, 'late_arrival');
```

## ⚠️ ملاحظات مهمة

1. **النقاط السالبة** = خصم تلقائي. `processAction` يكتشفها من `$setting->points < 0` ويستدعي `deduct` بدلاً من `award`.

2. **أولوية الفرع**: إذا وُجد إعداد خاص بالفرع (`branch_id`) + إعداد عام (`branch_id = null`)، يأخذ إعداد الفرع الأولوية.

3. **الحد الأقصى للنقاط** (`max_points`): لا يمكن تجاوزه في أي معاملة واحدة.

4. **الحد الأدنى للمبلغ** (`min_amount`): إذا كان المبلغ أقل منه، لا يتم منح أي نقاط.

5. **`action_type` + `user_type`** = مفتاح فريد. نفس الـ `action_type` يمكن أن يكون له إعداد مختلف للعميل والموظف.

6. **العكس**: لا يحتاج `action_type` منفصل. يتم عبر `reverse()` أو `reverseByReference()` التي تنشئ معاملة عكسية بنقاط سالبة.
